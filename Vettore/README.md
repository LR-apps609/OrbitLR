# vettore

Il motore di «Vettoriale (SVG)» di OrbitLR. È lo stesso codice di `Vettore/` nel ramo `main` (app per Mac) e di `Windows/vettore` nel ramo `windows`:
le due copie devono restare uguali (cambiale insieme). L'app per Mac lo usa come programma `orbit-vector`
(Resources/Motori), compilato da GitHub per Apple Silicon e Intel.
